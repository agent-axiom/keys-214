# 214 ключей · Иероглифика

Статический учебный сайт на русском языке по мотивам карточного метода книги А. П. Мыцика.

- Полный набор из 214 традиционных ключей Канси.
- Шесть тематических групп; поиск по знаку, номеру, значению и пиньиню.
- Позиционные варианты, упрощённые формы и 124 примера.
- Собственные ассоциации для запоминания.
- Тренировка по 10, 20 карточкам или всей выбранной группе.
- Повторение забытых ключей и отметки в localStorage.
- Адаптивная верстка и управление с клавиатуры.

## Устройство

`dist/` — готовый сайт без сборки и внешних зависимостей. Точки входа: `#catalog`, `#practice`, `#about`, `#key-85`.

`content.tsv` содержит оригинальные русские карточки. `sources/` — происхождение данных и извлечённые факты Unicode. `python build-data.py` обновляет модуль `dist/data.js`.

Данные о прогрессе привязаны к браузеру. Сервис не содержит учётных записей или серверного хранилища прогресса.

Сведения об источниках, правах и границах учебных пояснений доступны внутри сайта в разделе «О проекте» и в `sources/README.md`.

## Запуск локально

Требуется Python 3. В корне репозитория:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Запускайте сайт через HTTP: при открытии `index.html` как локального файла браузер может блокировать JavaScript-модули.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.

Workflow `.github/workflows/pages.yml` пересоздаёт карточки, проверяет синтаксис JavaScript и публикует каталог `dist/` при каждом обновлении ветки `main`. Также доступен ручной запуск через **Actions → Publish GitHub Pages → Run workflow**. Внешние пакеты для сборки не нужны.

Относительные пути к ресурсам и навигация через `#` позволяют размещать сайт в подкаталоге GitHub Pages. Адрес опубликованного сайта отображается в **Settings → Pages** и в результате workflow.

Для изменения карточек отредактируйте `content.tsv` или `build-data.py`, выполните `python3 build-data.py` и сохраните изменения в GitHub. Для изменения интерфейса редактируйте `dist/index.html`, `dist/style.css` и `dist/app.js`.

Прогресс в `localStorage` привязан к домену: при переходе с другого хостинга отметки автоматически не переносятся.
